# Politique de confidentialité — Project : REVIVE

Dernière mise à jour : 24 octobre 2026

## 1. Introduction

Cette politique explique quelles données Project : REVIVE peut traiter lorsqu’il est utilisé sur Discord.

## 2. Données susceptibles d’être traitées

Selon les fonctionnalités utilisées, le bot peut traiter :
- les identifiants Discord des utilisateurs et des serveurs ;
- les identifiants des salons et des rôles nécessaires à sa configuration ;
- les messages et raisons fournis dans les formulaires de tickets ;
- les données nécessaires aux niveaux, à l’expérience et aux classements ;
- les informations nécessaires à la modération et aux journaux d’activité.

La liste exacte dépend du fonctionnement et de la configuration réels du bot.

## 3. Utilisation des données

Ces données peuvent être utilisées pour assurer les fonctions du bot : modération, tickets, annonces, niveaux, classements et musique.

## 4. Conservation et suppression

Les données peuvent être conservées dans les fichiers de stockage du bot ou dans les journaux du serveur, selon la fonctionnalité concernée. Pour demander l’accès à des données ou leur suppression, contacte l’équipe de Project : REVIVE via le canal de support prévu à cet effet.

## 5. Partage des données

Les données ne doivent pas être vendues. Certaines informations peuvent être traitées par Discord ou par des services tiers nécessaires au fonctionnement d’une fonctionnalité.

## 6. Sécurité

Des mesures raisonnables doivent être prises pour protéger les données et limiter l’accès aux fichiers de configuration et aux journaux.

## 7. Modifications

Cette politique peut être mise à jour. La version publiée sur cette page fait foi.

## 8. Contact

Pour toute question relative à cette politique, contacte l’équipe de Project : REVIVE via les canaux de support du projet.
